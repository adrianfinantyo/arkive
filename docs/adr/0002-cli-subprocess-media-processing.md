# Subprocess Media Pipeline via vipsthumbnail and FFmpeg with Core Isolation

Arkive requires generating WebP image previews and video keyframes on an Intel Pentium E5400 (2C/2T) while strictly maintaining <100MB idle RAM and avoiding daemon crashes. We decided to execute `vipsthumbnail` and `ffmpeg` as isolated child processes under strict OS confinement (`nice -n 19`, `ionice -c 3`, `taskset -c 1`, `prlimit --as=512M`) instead of using pure Go libraries or in-process Cgo bindings (`bimg`). Subprocess execution ensures zero Go GC heap bloat (images never allocate in the Go runtime), insulates the Go server from C library segfaults on corrupted files, leverages libjpeg-turbo DCT shrink-on-load to reduce decoding CPU by up to 8x, and guarantees Core 0 remains completely unblocked for HTTP and database traffic.
