# REST API Contract, Keyset Pagination, ETag Validation, and Type Generation

Arkive requires predictable HTTP API contracts with minimal CPU and memory overhead on low-power hardware (Intel Pentium Dual-Core E5400, 3.8GB RAM) while serving an embedded SvelteKit virtualized gallery (40 to 60 DOM nodes). We decided to use flat JSON models for single resources, dedicated collection wrappers (`{ items: T[], next_cursor: string | null, has_more: boolean }`) for list endpoints, and RFC 7807 Problem Details (`application/problem+json`) for errors, avoiding wrapper serialization allocations in Go and nested unboxing in TypeScript. Media gallery listings use keyset cursor pagination on `(taken_at DESC, id DESC)` with an opaque Base64 cursor, ensuring O(1) constant-time B-tree index queries across 50,000+ items on PostgreSQL and SQLite without index-scan degradation or row-shift anomalies during uploads. Timeline and folder listing endpoints implement HTTP `ETag` and `If-None-Match` validation backed by atomic version counters in Valkey (`user:{id}:timeline:version`), returning instant HTTP 304 Not Modified responses in under 0.2ms without hitting the relational database. API contracts are maintained using `tygo` via `go generate`, automatically compiling Go DTO structs from `internal/api/dto/` into TypeScript interfaces in `frontend/src/lib/types/api.gen.ts` to prevent contract drift while isolating internal GORM models from client visibility.
