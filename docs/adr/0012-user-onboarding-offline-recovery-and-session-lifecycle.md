# User Onboarding, Offline Password Recovery, and Session Lifecycle

To support non-technical homelab and family deployments without external SMTP dependencies, Arkive implements an invite-based onboarding workflow, a three-tier offline recovery architecture, and Valkey-backed persistent sessions. User onboarding relies on Admin-generated invite tokens (`/join/:token`) with configurable expiration and usage limits, pre-assigning roles (Uploader or Viewer) and Groups in a single registration transaction. In place of outbound email verification, password recovery operates across three complementary tiers: Admin-generated single-use reset links for family members, offline emergency recovery keys (Argon2id-hashed alphanumeric tokens issued during onboarding) for self-service recovery, and an administrative CLI command (`arkive admin reset-password`) for host console access. First-run setup auto-detects zero-user state in memory, routing traffic to `/setup` to initialize the primary Admin without static default credentials, locking the setup route permanently upon completion. Client sessions persist for 30 rolling days via `HttpOnly` and `SameSite=Lax` cookies, mapped in Valkey under `session:<token>` and indexed by `user_sessions:<user_id>` sets for immediate, single-command session revocation across devices upon logout, password reset, or role changes.
